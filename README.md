# LoveLink 💕 & 💙 (Private WA Companion App)

Aplikasi Android pribadi untuk menautkan WhatsApp dari jarak jauh (**LDR**) tanpa perlu scan QR Code (menggunakan fitur resmi **8-Digit Pairing Code** WhatsApp).

---

## Fitur Utama

1. **LoveLink Girl (Khusus Cewek) 💕**:
   * Desain **Soft Pastel Pink & Rose** yang gemas dan aesthetic.
   * WhatsApp Web otomatis diubah gayanya menjadi Pink Pastel lembut dan sudut membulat.
   * Tombol interaktif animasi hati (`💕`) berterbangan di layar.
   * Menu panduan pairing 8 digit jarak jauh langsung di dalam aplikasi.

2. **LoveLink Boy (Khusus Cowok) 💙**:
   * Desain **Midnight Dark Blue** yang bersih, modern, dan elegan.
   * WhatsApp Web dengan tampilan dark mode responsif.

3. **Bisa Tautkan Jarak Jauh (Tanpa QR Code)**:
   * Langsung mendukung fitur resmi **"Tautkan dengan nomor telepon"**.
   * Cukup masukkan nomor telepon $\rightarrow$ dapat kode 8 karakter $\rightarrow$ masukkan di WA utama.
   * Sesi login tersimpan permanen di HP masing-masing tanpa perlu scan/login ulang.

---

## Cara Otomatis Mendapatkan Link Download APK:

1. Buka [github.com/new](https://github.com/new) di browsermu.
2. Beri nama repository, misalnya: `lovelink` (pilih **Public** atau **Private**).
3. Klik **Create repository**.
4. Di terminal laptop ini, jalankan perintah:
   ```bash
   cd c:\Users\USER\Documents\wa\lovelink
   git init
   git add .
   git commit -m "Initial commit LoveLink APK"
   git branch -M main
   git remote add origin https://github.com/ipinhahz-bot/lovelink.git
   git push -u origin main
   ```
5. Buka tab **Actions** atau tab **Releases** di repositorimu di GitHub:
   * Tunggu sekitar 2-3 menit hingga proses compile selesai.
   * Kamu akan langsung mendapatkan **link download file `LoveLink-Girl.apk` dan `LoveLink-Boy.apk`**!
6. Kirim link atau file `LoveLink-Girl.apk` ke WhatsApp cewek kamu untuk langsung di-install di HP Android-nya.
